04 / METHODOLOGY AND LIMITATIONS

Protocol, audit and scope

This is a small pilot benchmark of semantic search with feedback, not a measure of general intelligence or coding capability.

Benchmark and scoring

Each round hides one English target word inside a frozen 50,000-word vocabulary ranked by cosine similarity on ConceptNet Numberbatch 19.08 int8 vectors. Rank 1 is the exact answer. Unknown words, invalid formats, and duplicates all consume attempts from the 50-guess budget.

Primary quality metrics are solved count out of 10 and PAR2 attempts (unsolved rounds receive a 100-attempt penalty). Lower PAR2 is better.

Timing measurement

Interaction cycle time is the elapsed interval between consecutive CLI results in the same round, excluding the first result of each round. Every submission launched a fresh Bun CLI process and loaded the rank table.

Cycles bundle model reasoning, agent orchestration, process startup, and data loading. They are not provider TTFT or generation speed, and Codex versus Antigravity trials were not simultaneous.

Audit and model identity

All 1,620 CLI submissions (790 Sol and 830 Neon) were audited with zero unexpected commands and zero human interventions. Every recorded rank matches the frozen tables.

Codex transcripts reported executedModel for both Sol runs. Antigravity did not report executedModel for Neon, so the Neon audit verifies the configured gemini-4-neon model and thought_level setting without independent backend identity verification.

Pilot scope and exclusions

Each participant attempted the 10 English tasks once in fresh agent contexts using baseline prompts that state rules without suggesting a search strategy. No independent repeats were run.

Russian tasks (ru-01 through ru-10) were not run and are excluded from all reported figures. Single-trial results on 10 selected words carry substantial variance and do not establish a general model ranking.
