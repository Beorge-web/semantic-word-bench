04 / METHODOLOGY AND LIMITATIONS

Protocol, audit and scope

This is a small pilot benchmark of semantic search with feedback, not a measure of general intelligence or coding capability.

Benchmark and scoring

Each round hides one target word inside the collection's frozen vocabulary and semantic rank tables. Rank 1 is the exact answer. Unknown words, invalid formats, and duplicates all consume attempts.

Primary quality metrics are solved count and PAR2 attempts. Unsolved rounds receive twice the attempt budget as a penalty. Lower PAR2 is better.

Timing measurement

Interaction cycle time is the elapsed interval between consecutive CLI results in the same round, excluding the first result of each round. Every submission launched a fresh Bun CLI process and loaded the rank table.

Cycles bundle model reasoning, agent orchestration, process startup, and data loading. They are not provider TTFT or generation speed, and Codex versus Antigravity trials were not simultaneous.

Audit and model identity

Audit metadata is loaded with the selected task set.

Codex transcripts reported executedModel for the published Sol and Astra runs. Antigravity did not report executedModel for Neon, so the Neon audit verifies the configured gemini-4-neon model and thought_level setting without independent backend identity verification.

Pilot scope and exclusions

The English pilot used one trial per participant and fresh agent contexts with baseline prompts that state rules without suggesting a search strategy. Participants shared the filesystem. Command audits verified their recorded tool use; filesystem isolation was not enforced.

The selected collection determines the language and task set. Other collections do not enter its metrics. Small task sets and single trials carry substantial variance and do not establish a general model ranking.
